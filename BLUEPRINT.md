# MiniDSH Blueprint

Rolling long-term route plus a compact development record. Four sections, always in this order: what comes next, the macro route, what is still an open question, and a record that is compressed as it ages. `ARCHITECTURE.md` describes the current shape and its known limitations; this file says what comes next and why, and keeps the measurements the architecture map no longer carries.

## 1. Next session — S9 Context & prompt hygiene

Goal: close the two places where the model's view of a session is weaker than the log — history a compaction shadowed, and prose about authority written from the wrong layer — and measure one prompt sentence instead of arguing about it.

1. **A bounded recall tool.** `history_read{fromSeq, toSeq}` renders shadowed surface nodes through `deriveEventMessage`, restricted to seqs a `compaction/applied.shadowedSeqs` names, under a per-call and a per-session budget; it is registered in the agent's scope only after that agent's first applied compaction, and the summary message gains a code-written footer naming the shadowed range. Upstream ships no recall (a proposed note only); MiniDSH builds the minimum because the routing arc fails on a summary that dropped a fact the next turn needed (5 of 13 runs at the S8 tip, 1 of 4 at S7.5), and its log already stores every shadowed seq. A quality item, not a V1 blocker: no user compacts by pressure on the shipped DeepSeek default.
2. **Model-facing prose in one place.** The sandbox mode-switch note moves out of `core/sandbox` into `context-runtime` as one unscoped `session/event` listener on `sandbox/mode{change}` and `approval/policy{change}` (the approval switch has no note today, so the prompt keeps stating the opening policy); the enforcement line reads the stamp's recorded `enforcement` rather than the live shell world. One §7 contract sentence and one pinned test move with it.
3. **The "this host cannot confine shell commands, so the shell refuses" sentence, measured.** Upstream removed its analogous sentence after 5 of 12 turns ended with zero tool calls; MiniDSH's is true where upstream's was false and is what lets a model escalate on its first call instead of buying a dead refusal. Run the authority arc six times with and six without and count zero-tool-call turns and dead refusals before deciding.
4. **`Agent.world` and a tool tag** replace `tool-subagent`'s two process-global maps (the world a child composes; which registered tools are delegation tools): a `CreateAgentOptions.world` stored by the loop factory, and a `ToolDefinition.tags` the depth cap reads.

Verification: the context and routing arcs six times each, flake rate before and after; the authority arc for item 3. The tool-result pruner (upstream's model-free first pass) stays deferred, not rejected: it runs on the same pressure trigger the shipped default never reaches, and every shipped tool already bounds its own output.

**V1 is** the smallest release a developer can install, point at a repository, and use daily without reading the architecture: two interactive surfaces (`chat`, `web`) and one headless entry (`run`) over one runtime; the default preset `workspace-write` + `ask`, under which an ordinary task on a confined host costs zero prompts and an out-of-workspace effect one one-shot approval — and on a host with no backend the shell asks per call or the user chooses the `danger-full-access` preset, stated in the README and hinted at the first ask, never silent; keys from the environment or `~/.minidsh/credentials.json`, with the first failure naming both; `pnpm check` green on three platforms in CI and the eight live arcs green three times before the tag, the routing arc's flake rate reported rather than hidden.

**Out of scope for V1**, each with the reason the S8.5 research found: model-written extensions (opt-in even upstream — only its `cordis` preset — session-scoped, and its `node:vm` is stated five times not to be a security boundary; three vocabulary generations in ten weeks); background jobs, continuable children, mailboxes and Agent Teams (upstream's own `minimal` preset ships none; MiniDSH's one-shot foreground child is upstream's one-shot foreground path); parallel tool calls (an optional loop change with modest payoff for three tools); an MCP bridge (shipped disabled upstream); a Windows confinement backend (native bindings, standing ACL mutations, always `partial`); standing approval grants and allow-lists (deferred upstream pending a grant-scope identity); session deletion in the persistence seam (upstream has none anywhere: "session deletion needs its own lifecycle"); PTC / Code Mode; a session search index; per-user identity; a desktop shell.

Ordering rationale: the protocol before any GUI so surfaces never grow semantics; authority before configuration so presets cannot widen permissions silently; the route as a fact before roles and delegation; compaction before delegation because a fork-mode child inherits its parent's surface; verification after routing and after a checkpoint. Hardening checkpoints recur every two feature sessions, and the next one is the release gate.

## 3. Open questions (a decision is pending; the known limitations themselves live in ARCHITECTURE §13)

- **Which confinement backend first, and where is it proven?** `bwrap` is the cheapest real backend and runs under WSL 2 on the dev machine; `sandbox-exec` needs a macOS runner. Neither can be exercised on Windows itself. Settled by S11's CI matrix.
- **Background work and parallel tool calls.** Upstream's shapes are transferable if ever needed — the inbox as the only queue, an interrupt that parks rather than kills, a producer that must not start work its owner cannot collect, a per-tool `isConcurrencySafe` with results committed in model order. Nothing in the V1 route needs them; the first real need (a long verification, a watcher) decides.
- **A second surface writer.** Only the compaction planner enforces "a replace never separates a call from its result", and the session invariant admits a `replace`-op `user/message` outside a step but not a `tool/result`. A pruner would be that second writer; the rule moves into the session when one exists.
- **Concurrent children and the replay oracle.** Sessions are matched to logs in first-request order, which is exact while delegation is serial and undefined the instant it is not (upstream tracks the identical defect). Latent while one child runs at a time.
- **Two provider facts to design with, not around.** DeepSeek's `user_id` parameter gives each id its own rate budget — a ready-made seam for session identity; Anthropic caps a whole request at 32 MB with a 413 that maps to `INVALID_REQUEST`, which nothing retries and nothing compacts. Neither is used yet.
- **Install at V1.** The route says npm with a `prepack` emit; "clone-only" is the honest alternative for a reference implementation. Decided at S11.5 with the dry `npm pack`.

The skeptic refuted the pruner as a V1 item (it runs on a trigger the shipped default never reaches) and a `never` default for headless runs (a durable authority change; a wording fix was right). **Repairs:** a file-level acyclicity gate over core in `check-deps`; the agent vocabulary moved below its service; one fold pair in `core/session`; `compaction-basic` declaring what it always needed; `presentCall` deleted; one flag table driving usage and help, `--help` exiting 0, the composition layered once, `sessions` refusing authority flags, the sensitive set corrected; `[turn error: CODE — message]`; `SHELL_UNAVAILABLE` from the shell seam with no silent fallback to PowerShell 5.1; the approval line reworded under its pinned prefix; one tip on the first ask. - **S8 Verification capabilities (2026-09-02)** — the attachment plane and a verifier that is a composition row. Fourteen local probes decided the order: a constructed `image` block pushed through the tree changed NOTHING at six sites (the meter scored it 0, both serializers emitted byte-identical wire messages, `describeEvent`, `transcriptLines` and the browser's `row()` rendered the text alone) and none was a `switch` the compiler would flag, so the exhaustiveness guards landed before the variant. Live: DeepSeek's vision model reads a generated 4-quadrant PNG with streaming, tools and thinking; `deepseek-v4-flash` answers a 400 (`This model does not support image`) that must never be string-matched; Anthropic validates the declared media type against the bytes, caps a side at 8000 px, and DOWNSCALES a 4000×3000 image inside a `tool_result` rather than rejecting it (a panel HIGH refuted by probe); image cost measured on `count_tokens` as `min(⌈w·h/750⌉, 1600)` (96²→19, 256²→103, 512²→364, 1024²→1372, 2048²→1524 capped), DeepSeek bucketed at 116/200/348. Decisions worth keeping: the descriptor is STORED so a later wording change cannot rewrite what an old log says the model saw; the assistant-side image refusal lives in `validateStream`, not the assembler, because the driver appends the chunk first; the give-up counter is a fold bounded to `liveStart` (an unbounded one is a latch only a human `/compact` can lift, inherited by every fork); nothing new ships in `compose()` but a service row. The best review finding was not about images: `Fs.readBytes` emitting `fs/observed` would have handed the model a read-before-edit token for bytes it never saw. Verification: 564 tests (50 files), all eight arcs green, the new arc four times with identical evidence, about $0.02; the fixture is drawn `blue, white, red, green` because the canonical order is guessable from a filename. The routing arc's flake predates S8: 5 of 13 runs at this tip, 1 of 4 at the S7.5 tip.

- **S7.5 Architecture hardening & system review (2026-09-01)** — S6 and S7 read as one system. Sixteen probes found nine defects before any agent ran: a wire client could prompt a LIVE delegated child and the injected turn silently became the parent's tool result; a child's whole stream was broadcast to every un-narrowed client; the page event ceiling bound only at a message boundary, so a range with no arrived message returned the whole log (5,000 facts against a ceiling of 2,000); the browser never advanced its cursor across the trace tier, so every step spent a gap-repair round trip; `transcriptLines` rendered three kinds where `describeEvent` rendered eleven; three RFC 6455 frame shapes a server must reject were accepted. The audit's skeptics added what five lenses missed: an approval could be parked forever by a client that narrowed away, and a cold session offered dead approvals as live prompts. Load-bearing fix: one predicate — a child whose parent is live and which this host did not itself resume is read-only over the wire and attach-only on the stream. The approval fix deleted a field (answerers recomputed from live connections). The replay oracle's quietest defect: one cursor served every session, so a replayed child ate the parent's next recorded step while `assertConsumed()` passed on arithmetic; sessions now match logs in first-request order. Upstream research corrected fifteen claims of ~200 checked (no `model/selection` event; DSH salvages a torn tail; three client protocols not two; `session.fork` implemented with `atSeq`; escalation is upstream's gate too; ~150 packages understated by 2-3×). The diff review then found a HIGH defect this session introduced (the browser's `noted()` advanced the cursor off the shared promise queue — the hazard is the await, not the mutation). Closing took a second sitting: a summary 5 % BIGGER than the span it replaced (a real defect, now refused); a replay whose recording chose an absolute path the fence rightly refuses in another root (25 later path arguments were relative once the prompts said so); the S5 arc's premise decayed silently — "reply with the marker token" is answerable by one `Select-String`, a 16 s run against 45–105 s, zero context growth — so the prompts now name the editor tool; 14 of 34 summaries produced no compaction and two applied ones shrank the surface by 3 %. A review subagent junctioned `node_modules` into a scratch worktree and `git worktree remove --force` followed it; `.claude/hooks/guard-repo.mjs` refuses that shape mechanically. Verification: 492 tests (45 files).

- **S7 Web surface (2026-08-31)** — a third surface and the paging the log had been waiting for. Measured: a 400-turn session is 103,201 events and 17.0 MB of JSON; `session/events` cost 322 ms of `JSON.stringify` on the host's event loop; a page of 300 facts is 58 KB; a cold `persistence.load` is 167 ms and 28 MB; a hand-rolled RFC 6455 server round-trips a 200 KB frame with Node's own client. Decisions worth keeping: the cut does NOT honour a replacement's citations (a summary cites every node it shadowed); the host is per-deployment and a `ClientConnection` owns only a sink and a watch set; backpressure is tier-aware because `session/event` is a synchronous emit that cannot suspend its producer; `expectedRevision` is required on the settings wire. A real browser then found four things no protocol test could (`.banner{display:flex}` beating `[hidden]`; a stale status line; the settings pane saving resolved values with `replace`; `settings.changed` arriving before its own write's response). The review found four WebSocket codec defects, an inverted settings precedence, a stealable lock, a launch token called one-shot and never spent. Verification: 465 tests, seven arcs, about $0.02.

- **S6 Cognition routing & delegation (2026-08-30)** — the model became a capability the runtime routes to. Two probes decided the shape: a global `agent/request` rewriter reaches every agent, so a role would poison a resume unless the base route became its own fact; a tool body can already create, seed, drive and dispose a child bound to its parent's scope. Live provider probes caught what no document stated: DeepSeek refuses (400) an assistant tool-call turn whose `reasoning_content` is missing in thinking mode; Anthropic's 5 family returns 400 for any `temperature` while streaming thinking as an empty delta plus one signature. Decisions: the BASE route is a durable knob separate from the effective route; `resolveCallConfig` is the one resolution a step and an out-of-loop call share; a delegation opening is an enforced ceiling where DSH relies on the pin alone. The review found the delegation tool flushing the child before appending `subagent/end`, a fork that kept lineage while dropping the fence, and a grandchild re-running its grandparent's opening. Verification: 394 tests, six arcs, about $0.05.

- **S5.5 Architecture hardening & route review (2026-08-28)** — S1–S5 read as one system; 50 findings, 49 verified.
